# LEVELING

A lightweight, offline-capable cognitive training engine and procedural puzzle web application built with modular Vanilla JavaScript, HTML5, and CSS3.

## Live Demo
Play it directly in your browser: `https://dodgwekhd-creator.github.io/leveling/`

## Features
* **Procedural Puzzle Generators:** Dynamic challenges across **Spatial Rotation**, **Working Memory**, and **Deductive Logic**.
* **Deterministic State Machine:** Prevents race conditions, timer overlaps, and double-submission bugs during rapid input.
* **Adaptive & Curated Modes:** Switch seamlessly between procedural generation and structured challenges.
* **Zero Dependencies:** Runs natively in any modern browser with no external frameworks or build tools required.

## Project Structure
* `index.html` — Semantic application layout and controls
* `style.css` — Dark-mode UI styling and responsive grid system
* `app.js` — Finite state machine, timer registry, and puzzle logic
